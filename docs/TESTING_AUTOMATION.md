## 如何使用测试工具

### 运行测试
```bash
# 运行所有测试（无头模式）
pnpm test

# 查看浏览器运行过程
pnpm test:headed

# 打开交互式 UI
pnpm test:ui

# 查看 HTML 报告（包含截图、视频）
pnpm test:report
```

### 调试失败的测试
```bash
# 只运行失败的测试
pnpm exec playwright test --last-failed

# 运行特定测试文件
pnpm exec playwright test tests/math-feature.spec.ts

# 使用调试模式
pnpm exec playwright test --debug
```

### 查看测试证据
```bash
# 测试结果目录
ls test-results/

# 每个失败测试都有：
# - screenshot.png（失败时的截图）
# - video.webm（完整操作录像）
# - error-context.md（错误上下文）
```
