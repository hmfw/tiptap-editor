### 🔧 测试代码需要改进的地方

失败的测试并非功能问题，而是测试编写问题：

1. **演示页面内容干扰**
   - 问题：演示页面预先填充了示例内容，导致选择器匹配到多个元素
   - 解决方案：测试前清空编辑器内容，或使用更精确的选择器

2. **Placeholder 选择器**
   - 问题：`.tiptap-placeholder` 类名可能不正确
   - 解决方案：需要检查实际 DOM 结构

3. **Strict Mode 冲突**
   - 问题：Playwright 的 strict mode 要求唯一元素匹配
   - 解决方案：使用 `.first()` 或更具体的选择器
